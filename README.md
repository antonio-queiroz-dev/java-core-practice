# Java Core Practice

Exercícios diários de Java Core focados em fixação profunda de conceitos, com progressão gradual de dificuldade. Cada fase é estudada até dominar antes de avançar para a próxima.

## Estrutura

```
src/
├── a_for_acumulador/         # Loops, somas, contadores                (6 + 18 revisão)
├── b_comparacao_elementos/   # Busca de maior, menor, segundo maior    (6 + 15 revisão)
├── c_arraylist_strings/      # Manipulação de listas e strings         (6 + 16 revisão)
├── d_hashmap/                # Iteração, lógica com Map, internals     (8 + 47 extras + 71 revisão)
│   ├── aula/                  # Guia teórico de referência
│   ├── extras/                # Exercícios de aprofundamento
│   └── revisao1/              # Rodada de revisão dos padrões da fase
├── e_streams/                # filter, map, sorted, reduce, groupingBy (89 exercícios)
│   └── aula/                  # Guia teórico de referência
└── f_sql/                    # SELECT, WHERE, ORDER BY, agregações     (8 exercícios)
    └── aula/                  # Guia teórico de referência

_rascunhos/                    # Testes rápidos e experimentos avulsos
```

Cada fase concluída traz um `README.md` listando seus exercícios. As fases com guia teórico (`d_hashmap`, `e_streams`, `f_sql`) mantêm o material de estudo em `aula/`.

## Abordagem

- Um tema por vez, estudado até fixar antes de avançar
- Exercícios resolvidos manualmente, sem copiar soluções
- Progressão: fundamento → aplicação → combinação de conceitos
- Nomenclatura de pastas: prefixo alfabetico (`a`, `b`, …) preserva a ordem do estudo

## Tecnologias

- Java 21
- PostgreSQL (fase `f_sql`)
