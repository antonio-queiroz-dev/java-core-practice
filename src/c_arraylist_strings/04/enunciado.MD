**Fase 3, Exercício 4 — Palavra mais longa**

Dada uma frase (String com espaços), retorne a **palavra mais longa**.

```java
public String palavraMaisLonga(String frase) {
    // seu código aqui
}
```

**Exemplos:**

```
Entrada: "eu gosto de programar"
Saída: "programar"

Entrada: "o sol nasceu"
Saída: "nasceu"

Entrada: "oi"
Saída: "oi"
```

**O que você precisa saber:**
- `frase.split(" ")` divide uma String por espaços e retorna um **array de Strings**
- Depois é o mesmo padrão da fase 1: percorrer e guardar o maior
