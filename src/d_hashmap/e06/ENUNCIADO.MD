**Fase 4, Exercício 6 — Número que mais aparece**

Dado um array de números inteiros, retorne o **número que aparece mais vezes**.

```java
public int numeroMaisFrequente(int[] nums) {
    // seu código aqui
}
```

**Exemplos:**

```
Entrada: [1, 2, 2, 3, 3, 3]
Saída: 3

Entrada: [5, 5, 1, 1, 5]
Saída: 5

Entrada: [7]
Saída: 7
```
